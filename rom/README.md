# Local input only

Place your own legally obtained ROM here locally if you want to run the optional analysis tools.
Do not upload it.
The public file allowlist permits this README, not ROM files.

The investigated USA/Europe revision has these identifiers:

```text
size   131072 bytes
CRC32  0030E61F
MD5    63e3f5f4b90f17bdf6d2f2aed515e248
SHA-1  1da5834cd7cea711195cd8581614c5022da768b7
```

Run `python tools/verify_project_inputs.py` from the repository root before using game-specific tools.
The verifier requires exactly one `.gb` or `.gbc` file in this directory.
No ROM, save state, or download location is supplied.
